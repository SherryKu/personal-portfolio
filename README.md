# Kexun (Sherry) Liu — Portfolio

Personal portfolio for an AI Product Engineer working across product definition, UX, full-stack engineering, systems design, and applied AI.

## Local development

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production build

```bash
pnpm build
```

The repository includes a GitHub Actions workflow that exports and publishes the site to GitHub Pages whenever `main` is updated.
